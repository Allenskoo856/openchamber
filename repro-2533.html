Reproduction: Issue #2533

Android: long dictation transcript pushes Cancel/Insert/Insert-and-send controls off-screen. The composer lacks viewport-constrained height and overflow: hidden when dictation is active, causing the form to grow beyond the visible viewport.

❌ Bug: Current behavior (Android)

Chat messages area (viewport fills above form)

Long dictation transcript:

This is a very long dictated message that keeps growing as the user continues speaking. The transcript content is not constrained to the viewport height because the form and its parent containers don't limit their height when dictation is active on Android.

The composer grows taller and taller as more text is dictated, pushing the footer with Cancel, Insert, and Insert-and-send buttons further and further down. Eventually, these controls are pushed completely off the visible screen.

This makes it impossible for the user to submit their dictated message, effectively trapping them in the dictation flow with no way to complete the interaction.

Technical Analysis

Root cause chain:

  1. When dictation starts from the mobile pill, mobileShell.expanded becomes true but isExpandedInput (global UI store) stays false. The form does NOT receive the expanded layout classes (flex h-full min-h-0 flex-col).
  2. The form remains a block element with content-determined height — no viewport constraint.
  3. As the dictation transcript grows, onContentHeightChange reports the content height via dictationContentHeight, which is applied as minHeight on the editor container (ChatInput line 2596).
  4. The minHeight grows the editor container → the composer box → the form. No ancestor has overflow: hidden or max-height, so the form grows without bound.
  5. The absolutely-positioned dictation overlay (absolute inset-0) covers the growing composer. Its footer with Cancel/Insert/Insert-and-send buttons is pushed below the visible viewport.
  6. useMobileViewportPin which would pin the form to the visual viewport is skipped for Capacitor apps (early return when isCapacitorApp()).
