MacOS Vibrancy Reproduction

The sidebar background is translucent (rgb(28 27 26 / 0.66)), simulating the native macOS vibrancy effect. The checkerboard represents the desktop wallpaper visible through the frosted sidebar.

Zone headers (outlined in red) use background: var(--sidebar-stuck-bg) !important which is fully opaque #1C1B1A. In normal (non-vibrancy) mode these blend with the solid sidebar. In vibrancy mode they render as opaque dark blocks — the "black fill."

Root cause: design-system.css line 160-165 forces .oc-zone-header-backing to use opaque var(--sidebar-stuck-bg) as a workaround for Electron#20357 (backdrop-filter broken on transparent windows). When vibrancy makes the sidebar translucent, these sticky zone headers become visible opaque blocks.
