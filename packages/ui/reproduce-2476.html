With explicit text color on hover, text remains legible.

Reproduction steps:
  1. Use VS Code with "Dark High Contrast" theme (or any theme where toolbar.hoverBackground or list.hoverBackground is white/light).
  2. Open the model selection dropdown (e.g., in Agent settings).
  3. Hover over any model in the list.
  4. The text becomes difficult to read because the hover background is white/light while the text remains white.
Root cause: ModelPickerList.tsx:609 applies hover:bg-interactive-hover/50 but does not set a hover text color. In high-contrast themes, --interactive-hover resolves to a light/white color, while the text remains --surface-elevated-foreground (also white). The resulting contrast between white text and the blended hover background (~#8F8F8F) is only ~3.2:1, failing WCAG AA (4.5:1).

Fix: Add hover:text-foreground (or better, a dedicated hover foreground token) to the model picker row styling, so text color adapts on hover.
